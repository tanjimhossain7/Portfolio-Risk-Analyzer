# Portfolio-Risk-Analyzer
# 📉 Portfolio Risk Analyzer — Value at Risk (VaR) Modeling & Dashboard

This project explores how to measure and visualize **financial risk** in a stock portfolio using real historical data. It includes both a **Jupyter Notebook** for statistical exploration and a fully functional **Streamlit dashboard** that anyone can use to simulate portfolio losses, estimate Value at Risk (VaR), and run stress tests.

---

## 🚀 What It Does

- Calculates **daily log returns** for a portfolio of stocks (AAPL, MSFT, GOOGL, AMZN, NVDA)
- Implements **three VaR models**:
  - Historical VaR
  - Parametric VaR (variance-covariance method)
  - Monte Carlo simulation
- Computes **CVaR** (Conditional VaR / Expected Shortfall)
- Runs **stress test scenarios** (e.g., all stocks drop 5–15%)
- Visualizes return distributions and VaR thresholds
- Offers an **interactive web app** built with Streamlit for live input/output
